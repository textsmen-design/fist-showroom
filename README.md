# fist-showroom · FIST × GONKA LAB

> **RAW IDEA IN. EXCEPTIONAL PRODUCT OUT.**

Публичная витрина цифровой лаборатории **GONKA LAB** (`fist.gonka.blog`).

Показывает принципы работы команды FIST, интерактивные сценарии («от неуклюжей мысли к готовому продукту»), девять пит-стопов цифрового производства и первый публичный инструмент лаборатории — **[FIST Guard](https://github.com/textsmen-design/fist-guard)**.

---

## 🛠 Особенности реализации

* **Чистый веб-стек:** Vanilla HTML5, CSS3, JavaScript (ES2022). Никаких внешних библиотек, CSS-фреймворков и этапов сборки.
* **Строгая безопасность:** Content Security Policy (`default-src 'self'`), отсутствие внешних скриптов, трекеров и cookies.
* **Адаптивность:** протестировано от 375 px (мобильные устройства) до 1440+ px (десктоп), оптимизировано под экран MacBook Air 1280×800.
* **Графика:** векторный SVG логотип и легковесные WebP-изображения (общий вес страницы ≈ 0,5 МБ).
* **Связь в Релизе 1:** приём идей открыт напрямую через рабочую почту: `textsmen@yandex.ru`.
